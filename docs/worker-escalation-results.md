## Explicit named tasks: preview.18 source qualification (2026-11-05)

frontends to the existing fixed roles. A task can request review/validation,
investigation or implementation while the initiating primary retains decisions
and acceptance. Explicit choice needs neither loaded-primary detection nor an
adaptive escalation preference, and grants no persistent automatic permission.
Review/investigation produces evidence without implementation edits. Native
permissions still apply; this is not an enforced read-only sandbox.

substantive defect was found. A final primary clarification permits bounded
investigation to gather missing facts rather than requiring a solved handoff.

## Implemented policy

The [selected design](worker-routing-design.md#selected-design-primary-luna-and-one-escalation-target)
and [implementation plan](https://github.com/byebyebryan/codex-plus/blob/295ed24061d058067e8d2a18ee39a3f55d610067/docs/codex-plus-plan.md#selected-plan-primary-luna-and-optional-escalation)
keep the native user-selected primary, useful Luna assignments and one opt-in
escalation target. Terra can select Sol or Astra; Sol can select Astra. Defaults
are none. Reviews and demanding implementation use the same option. There is no
new preference file, custom native setting, router service, automatic Sol/Terra
cost substitution or recursive escalation ladder.

Only `worker-task` and `worker-goal-loop` gain the selection policy. The native
`astra-xhigh` role pins `gpt-6-astra` / `xhigh`; `sol-xhigh` remains
`gpt-6.1-sol` / `xhigh`. The Luna role and both explicit Luna skills, including
invocation metadata, remain byte-identical to the goal baseline. Generic goal
requests and skill discussion activate no worker skill. Explicit named native
worker requests retain their separate authority.

The existing source `codex-plus-context --primary` helper supplies qualified
loaded-thread selection. It does not prove a backend inference identity, guess
from host defaults or revive an unloaded thread. Worker-only installs remain
useful without the helper or monitoring: unknown primary identity holds automatic
escalation and preserves primary/Luna work. Native role pins, account eligibility,
completed execution and accepted work remain distinct evidence.

## Review fixes: optional metadata and packaged documentation

The subsequent review found that a reporting-only archive shipped the context
CLI without `codex_plus.native`, causing `--primary` to raise before producing
JSON. The fix resolves a missing caller before importing the optional client and
returns `unknown` / `native_component_unavailable` when that module is absent.
Only the absent native module is treated as optional; unrelated import failures
are not concealed. No monitoring dependency, owner startup or fallback endpoint
is added. Ordinary offline context reporting remains unchanged.

The worker archive now includes this qualification record. Its relative document
links resolve within the archive; references to the larger implementation plan
use an immutable source URL. Tests execute the relocated real reporting archive
with and without a caller and with no command search path, and walk relative
links in the actual worker archive. Both regression tests fail against `a8aaa2e`
and pass with fix `92be2d6`. The complete core suite passes 385 tests, the 135-file
inventory and unified private build/verification. Worker roles and all four skill
bodies/invocation metadata remain byte-identical to the review baseline.

The separate matched permission trial is scoped to one fresh continuing Sol
primary and an unchanged, intentionally defective lease fixture. The same
read-only review request is used with escalation permission omitted, explicitly
enabled for Astra, then revoked before a new assignment. Only the enabled/disabled
preface changes. This is a test of the agent's interpretation of instructions;
it introduces no parsed configuration flag or spending enforcement. The trial is
bounded to four worker starts and twelve native conversation turns, with a stop
after two distinct provider/access failures. The settled results below are separate from the earlier pilot evidence.

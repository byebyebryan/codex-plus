How the tools work together

A code review can be a one-off request. If it turns up a bug, you can use the other tools to see the fix through in the same Codex conversation.

  1. Get a second opinion

    Ask Astra to review a CSV importer. It spots a case where retrying an interrupted import writes the same row twice.

  2. Split the work

    Ask the agent in your docs session to update the retry instructions while your primary agent fixes the importer.

  3. Watch the tests

    Ask Codex to watch CI while you keep working. It reports back when the retry test passes or fails.

  4. Show what changed

    Ask for an HTML report comparing row counts from the same import before and after the fix. Include the test result alongside them.
